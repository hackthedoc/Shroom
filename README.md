# Shroom

> EARKY DEVELOPMENT

Shroom Engine is a modern C++ game engine focused on performance, simplicity, and developer experience.

The goal is not to recreate Unreal Engine, but to create a clean, understandable engine that  demonstrates modern engine architecture while remaining capable of powering real games.

The target audience is indie developers, engine programmers, students, open-source  contributors and myself.

Eventually, Shroom Engine should support 2D and 3D  games, a modern Vulkan renderer, a custom editor, hot reloading, an asset pipeline, ECS, plugin support and cross-platform development.

---

## Development

Shroom Engine is being developed live on Twitch from the very first line of code.

Every major feature, architectural decision, and milestone is built in public, allowing anyone to follow and participate in the engine's evolution in real time.
